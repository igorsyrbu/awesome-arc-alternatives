A curated list of browsers that carry on the ideas of [Arc](https://arc.net): vertical tabs, spaces, a command bar, and a calm interface.

**Arc stops working on December 22, 2026.** The Browser Company is [sunsetting Arc](https://arc.net) in favor of Dia. This list helps you pick where to go next, whether that is Dia or something else.

**Browse it as a page:** https://igorsyrbu.github.io/awesome-arc-alternatives
